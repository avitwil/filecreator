# filecreator

A small interactive command-line tool (`PythonProject13/main.py`) for creating and tracking
text/Python/bash files, and for registering shortcut "commands" that re-run a given script later.

## Requirements

- Python 3.10+ (uses `match` statements)
- [`keyboard`](https://pypi.org/project/keyboard/) (`pip install keyboard`) — reads single
  key presses for the interactive menu. On Linux this typically requires root privileges.

## Usage

```bash
cd PythonProject13
python main.py
```

You'll get a menu to:

1. **Create new file** — prompts for a file name, path, and type (`python`, `bash`, `text`, or
   left empty for a plain/no-extension file). Python and bash files get an appropriate shebang
   line and (on POSIX systems) executable permissions. You can also register a "command" name
   for the new file so it can be re-run later. On POSIX systems the file is opened in `nano`
   for editing once it's created.
2. **See file list** — lists every file previously created via this tool (tracked in
   `file_list.txt`).
3. **See command list** — lists registered commands (tracked in `command_list.txt`) and lets
   you run one, which executes the associated python/bash script (POSIX only).

Press `Esc` at the main menu to exit.

## Notes

- `file_list.txt` and `command_list.txt` are runtime data generated by the tool itself (they
  record file paths on whatever machine you run it on), so they are gitignored rather than
  committed — sample/personal-machine copies from earlier are not tracked anymore.
- Running a registered command executes the associated script from disk (`os.system` for the
  `bash`/`python` types) — only add commands for scripts you trust.
